# HealthcareHub

HealthcareHub is a public Medicare and Medicaid spending intelligence platform.

## V1 Goals

HealthcareHub will provide:

- Medicare and Medicaid reported spending from 2020 to present
- Medical and prescription drug spending categories
- National, state, and county geographic analysis
- Quarterly and annual spending trends
- Spending per beneficiary where supported
- Source transparency and downloadable supporting detail
- Data pipeline health and refresh visibility

## Technology

- C# / .NET 10
- ASP.NET Core Web API
- React / TypeScript
- SQL Server / Azure SQL
- Azure
- PowerShell
- GitHub Actions

## Status

Early development.

Current milestone:

- ASP.NET Core API initialized
- Health endpoint available at `/api/health`

## Data Sources

HealthcareHub will use official public government healthcare datasets. Exact V1 source datasets are being documented before ingestion begins.
